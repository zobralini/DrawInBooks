# docs

Media for the Modrinth page and the README.

`overview.gif` is the one linked from both, at:

```
https://raw.githubusercontent.com/zobralini/DrawInBooks/main/docs/overview.gif
```

That URL only works once the file is committed and pushed to `main` — the path
in the link is the path in the repo.

Keep it under a few MB. Anything bigger belongs in the Modrinth gallery
instead, since every version of a file committed here stays in the repo's
history forever.
